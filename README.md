# 📚 Android2025_G1

Repositorio de apoyo académico con **materiales, ejercicios, evaluaciones y recursos del proceso formativo Android/Mobile 2025**.

## Descripción

La estructura está organizada por módulos e incluye PDFs, imágenes, ejemplos Java, scripts SQL, documentos de evaluación y recursos de estudio. No corresponde a una sola aplicación ejecutable, sino a una colección de material técnico y pedagógico.

## Objetivo

Centralizar los contenidos del proceso de formación para consulta, seguimiento y reutilización como material de estudio.

## Uso

Explora el contenido módulo por módulo según el tema o actividad que necesites revisar.
