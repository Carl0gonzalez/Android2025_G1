# 📚 Android2025_G1

Repositorio de apoyo académico con **material de clases, guías, ejercicios y recursos del plan formativo Android/Mobile 2025**.

![Android](https://img.shields.io/badge/Android-formación-3DDC84?logo=android) ![SQL](https://img.shields.io/badge/SQL-material-lightgrey)

---

## 📌 Objetivo

Centralizar apuntes, ejercicios, PDFs, ejemplos Java/SQL y material de apoyo utilizado durante el proceso formativo.

## 🧩 Contenido del repositorio

- Material PDF por módulo.
- Ejercicios prácticos en Java.
- Scripts y apuntes SQL.
- Recursos visuales y documentos de apoyo.
- Material de evaluaciones integradoras.

## 📁 Organización general

```bash
Android2025_G1/
├── Modulo 1/
├── Modulo 2/
├── Modulo 3/
├── Modulo 4/
└── Modulo 5/
```

## ▶️ Uso

Este repositorio no está pensado como una aplicación única para ejecutar, sino como biblioteca de apoyo y estudio. Revisa cada módulo según el tema correspondiente.

## 💡 Valor del repositorio

Es útil como respaldo documental del proceso de formación, seguimiento de contenidos y colección de ejercicios.
